# Data

* The data used in this project comes from a custom SEER session, which is included in the same directory. 
* The dataset represents Lung and Bronchus Cancer cases from the SEER database from 2010 - 2021, where age of the patient is known.
* The dataset is ~582,000 rows, so it has been included in the .gitignore. It can be modified/retrieved in the SEERSTAT application using the 'Lung and Bronchus.slm' file.


Surveillance, Epidemiology, and End Results (SEER) Program (www.seer.cancer.gov) SEER*Stat Database: Incidence - SEER Research Data, 17 Registries, Nov 2023 Sub (2000-2021) - Linked To County Attributes - Time Dependent (1990-2022) Income/Rurality, 1969-2022 Counties, National Cancer Institute, DCCPS, Surveillance Research Program, released April 2024, based on the November 2023 submission.
